# SVATON - Smart Vision AI Traffic Optimization Network

## Overview
SVATON is a comprehensive traffic management system that integrates 6 modules for real-time traffic optimization:

1. **Phase 2: Vehicle Detection** - YOLOv11-based vehicle detection
2. **Phase 3: Traffic Analytics** - Density analysis & metrics
3. **Phase 4: Signal Optimization** - RL-based signal timing
4. **Phase 5: Emergency Management** - Ambulance green corridor
5. **Phase 6: Traffic Prediction** - LSTM traffic forecasting
6. **Phase 7: Dashboard** - Real-time visualization

## Installation

```bash
# Clone or navigate to project directory
cd svaton

# Install dependencies
npm install
